Security

Security

DevMop deletes files, so it’s built to be careful by default. If you find a way it isn’t, we want to know.

Report a vulnerability

Please email YOUR-EMAIL with the details and steps to reproduce. Don’t open a public issue for security problems. You’ll hear back within a few days, and we’ll credit you when the fix ships if you’d like.

How DevMop is built

  • No network access: it never sends or downloads anything.
  • Every item is checked again right before removal, using what’s on disk now — never trusting an old scan.
  • It never follows links, never crosses into other disks, and refuses system, cloud-synced and .git folders.
  • It only ever stops processes you own, after confirming each one is still the same program.
  • It’s built only with Apple’s frameworks, with no third-party code.

Verify your download

Each release lists the SHA-256 checksum of its DMG. Compare it with:

shasum -a 256 ~/Downloads/DevMop-1.0.0.dmg
